# ぷらっとの歩き方

シェア型書店「ぷらっとBOOK」の来店者向けの棚診断アプリです。
5つの質問に答えると、今日の気分に合った読者タイプ（6タイプ）を判定し、おすすめの棚を3つ紹介します。

## 特徴

- **1ファイルで完結**：`index.html` だけで動きます。インストールは不要です。
- **通信しない**：答えた内容は、使う人のスマホの中だけで処理されます。外部への送信や保存はしません。
- **棚は毎回ランダム**：おすすめの3棚は、Fisher-Yatesシャッフルで毎回ランダムに選びます。どの棚も同じ確率で表示されます。
- **同じ答えなら同じタイプ**：合計点が同点のときは、Q4（今の状態）→ Q3 → Q2 → Q1 → Q5 の順に、その質問の点が高いタイプを選びます。
- **紙の診断シートにも対応**：紙の診断シートでタイプがわかっている人は、トップ画面から結果画面へ直接進めます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体。質問・配点・棚・推薦文は、ファイル内の `<script id="data">` にまとめてあります |
| `check.js` | 自動チェック。`node check.js` で実行します |
| `verify.html` | 検証ページ。ブラウザで開いてボタンを押すと、全576通りの計算と棚の抽選の確認を、その場で実行できます |

## 自動チェックで確かめていること

- 全576通りの答え方で、どれも1タイプに決まること。タイプごとの回数が設計どおりであること
- 10万回の抽選で、各棚が出る割合がほぼ30%（3/10）になること
- 外部へのリンクや読み込みがないこと

検証ページ：https://puratto-arukikata.github.io/verify.html
